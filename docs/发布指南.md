# 发布指南 / Publishing Guide

给 X-WIDE Use Everywhere 用的发布流程备忘（与本仓库 `pyproject.toml` 设置对应）。

- 目标仓库：`https://github.com/XWIDE/comfyui-xwide-use-everywhere`
- 包名（Registry）：`xwide-use-everywhere`
- `PublisherId`：`xwide`
- ComfyUI 里搜索显示的名字来自 `pyproject.toml` 的 `[tool.comfy] DisplayName` → **X-WIDE Use Everywhere**

---

## 一、在 GitHub 新建仓库

1. 打开 <https://github.com/new>
2. **Repository name 必须填** `comfyui-xwide-use-everywhere`
   （ComfyUI 生态约定：仓库名用 `comfyui-` 前缀；描述另填，不要写进名字里）
3. Description 建议：

   ```
   X-WIDE Use Everywhere - a fixed fork of cg-use-everywhere. Fixes UE virtual links and the flowing-link animation not being drawn in the browser. Nodes are drop-in compatible with the original.
   ```

4. 选择 **Public**
5. **不要**勾选 "Add a README file"、".gitignore"、"license"（本地已经有，勾了会冲突）
6. 点 **Create repository**

## 二、把本地内容推上去

仓库已经初始化并提交好了（见本目录父级的 `.git`），只需要绑定远端再推：

```powershell
cd C:\Users\Administrator\Downloads\comfyui-xwide-use-everywhere
git remote add origin https://github.com/XWIDE/comfyui-xwide-use-everywhere.git
git push -u origin main
```

（如果 GitHub 要求登录：用浏览器登录 GitHub 后，在推送时按提示用 Personal Access Token 当密码，
或先执行 `git config --global credential.helper manager` 让它弹窗登录。）

## 三、上架 Comfy Registry（让 ComfyUI Manager 能搜到并一键安装）

只有上架 Registry 之后，ComfyUI Manager 里才能搜到、才有缩略图。

```powershell
pip install comfy-cli
comfy node login          # 浏览器登录，Publisher 用 xwide
cd C:\Users\Administrator\Downloads\comfyui-xwide-use-everywhere
comfy node publish
```

要点：

- `pyproject.toml` 里 `[tool.comfy] PublisherId = "xwide"` 必须与登录的 Publisher 一致，
  不一致时按命令行提示改。
- **每次发布版本号必须递增**（改 `pyproject.toml` 的 `version` 与 `CHANGELOG.md`），否则会被拒绝。
- `Icon` 在 Registry 里必须是**完整 URL**（本项目填的是
  `https://raw.githubusercontent.com/XWIDE/comfyui-xwide-use-everywhere/main/docs/icon.png`），
  所以**必须先 push 到 GitHub，图片 URL 才能访问**，再执行 `comfy node publish`。
- Manager 里的节点缩略图只从 Registry 拉取，**不是**仓库里的 `preview.png`。

## 四、发布新版本

1. 改代码 → 更新 `CHANGELOG.md` → 递增 `pyproject.toml` 的 `version`
2. `git add -A; git commit -m "v7.8.2: ..."; git push`
3. `comfy node publish`

## 五、常见坑

| 现象 | 原因 |
| --- | --- |
| Manager 里搜不到 | 还没 `comfy node publish`（只 push GitHub 不会进 Manager） |
| 搜索名字不对 | 名字取自 `[tool.comfy] DisplayName`，不是仓库名 |
| 缩略图是空白 | `Icon` 不是完整 URL，或图片还没 push 到 main 分支 |
| 发布被拒 | `version` 没递增，或 `PublisherId` 与账号不符 |
| 装上后连线仍不显示 | 同时装了原版 cg-use-everywhere（节点 ID 相同，会互相覆盖），启动日志有告警 |
